# The avatar library

Fifty avatars in two sets, in the sticker style on a raised identity-colour disc (the offset depth
of the app's buttons; the team ring the component draws sits outside it). 120 × 120 viewBox SVGs,
PNG at 96 / 192 / 512 in each set's `png/`. Names are the `aria-label` only.

**characters/** — twenty-five crew: director, DoP, sound, gaffer, makeup, wardrobe, editor, producer,
script supervisor, actor, actress, runner, VFX, colourist, writer, location scout, broadcast,
casting, photographer, drone pilot, animator, line producer, host, critic, hair stylist.
**objects/** — twenty-five things from a production day.

## Rules
- A member with no photo gets one **at creation, at random across both sets** (`avatar_key` =
  `<set>/<key>`); it stays until changed.
- Changed from ملفي → صورتك: upload, the Google photo (`DEC-099`, when one exists), or pick from
  either set (two chips: شخصيات · أشياء).
- Rendered through `avatar`: photo → library SVG by key → initials (exports and email keep initials).
- Add an avatar only with a file here, a row in this table and a `DEC`; never retire a held key.
