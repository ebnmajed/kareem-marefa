# M10a — the member screens, batch A · specs for the rebuild

Companion to the canvas **كريم معرفة · M10a — Member screens** (13 artboards). Goes in the repo as
`docs/design/screens/M10a.md`. Reads under `docs/design/README.md`'s rule: `docs/plan/` and
`DECISIONS.md` win; a deviation is a `DEC-NEXT` proposal (§7), never a silent change.

Every artboard shows **one screen in its full state**; the other states are listed here, not drawn.
Numerals are Western everywhere (`DEC-124`). Copy is taken from `messages/ar/*.json` where a string
exists; new strings are marked ★. The five moments are `DEC-195`'s — none is added here.

Scope of the batch: **SCR-002 · 003 · 004 · 007 · 010 · 011 · 012 (three phases) · 014 · 016**, phone at
390 and desktop at 1280 for 010 and 012. Batch B: 013 · 015 · 017 · 018 · 019 · 020. Batch C: 021–028.

## 0. The shell, as drawn (applies to 010, 011 and every non-immersive screen)

**Phone.** Top row: wordmark (display face, accent) at start, `icon-button` search + `bell` at end.
Bottom `tab-bar`, **five tabs**: الرئيسية · الجلسات · **اقترح (raised accent circle, 56 px)** · الترتيب · حسابي.
Current tab = accent; others `fg-muted`. `env(safe-area-inset-bottom)` padding, `main` gains the
matching `padding-block-end` in the same commit (16 §3.1). The bar hides on immersive routes exactly
as `shell-routes.ts` already decides (`IMMERSIVE`), where the screen's own bottom action bar takes over.

**Desktop (≥ `lg`).** Top bar 64 px: wordmark (196 px column) · search entry 520 px · bell · account
menu (avatar with team ring + first name). Below it a three-column grid **220 / 600 / 340** with 24 px
gaps inside a 1280 container: **nav rail** (start, sticky; the big «اقترح جلسة» button, then الرئيسية ·
الجلسات · الأعضاء · لوحة الصدارة · حسابي, then a ruled الإدارة section with the queue count) ·
**content** · **game rail** (end, sticky). Browse and the hub use the same frame; the event page does not
(it owns its band, §5).

Deltas vs `16 §6.1`: five tabs, not four (الترتيب added; the leaderboard is a destination in a gamified
product, not a hub sub-page) · nav rail + game rail on desktop instead of a two-row header
(`REQ-UIX-021` asks for "two rows on desktop" — proposed as `DEC-NEXT-16`, §7).

## 1. SCR-002 sign-in · `Main.dc.html`

Regions, top to bottom: wordmark lockup (display 44, accent) + «من شبه الجزيرة» · `card` with `h1`
`auth.signIn.title`, `auth.signIn.subtitle`, **one** `button` primary-on-bone «الدخول عبر Google»
(Google's official mark goes in the 24 px slot — the artboard uses a placeholder), one explanatory
line ★ · a `panel` explaining the carried destination ★ («مسحت ملصق جلسة؟ … تصل إلى تلك الجلسة») ·
legal links. A `sticker` on the card corner («أول حضور = شارة») — the only playful object on the door.

States: **error** (`auth.signIn.error`, `route-error` inline above the button, never a toast) ·
**domain not allowed** → SCR-004, not an inline error · **already signed in** → redirect (unchanged).
No motion. `?next=` is carried unchanged (`REQ-AUTH-004`).

## 2. SCR-003 choose-org · `ChooseOrg.dc.html`

`radio-group` of the matched orgs (mark + name + domain), the chosen one bordered accent; a warning

## 3. SCR-004 no-access · `NoAccess.dc.html`

## 4. SCR-007 public card · `PublicCard.dc.html`

Brand row (wordmark + «من تنظيم <org>») · **`poster` whole, 4:5, never cropped** (`REQ-UIX-026`) —
the QR is *on* the poster and points here · status `badge` + seats line · `h1` · three icon rows

## 5. SCR-010 home · `Home.dc.html` (phone) · `HomeDesktop.dc.html`

**The home is the feed** (`DEC-NEXT-6`), not the sessions timeline; `/app` stops being
`/app/sessions` on a second route (`DEC-112`) and becomes its own page.

Phone regions: header · **`story-ring` row** (live ring accent-coral, unseen team-colour, seen `line`)
· **week HUD `card`**: rank / streak / points as three `stat` tiles + level `progress-bar` with the
«بقي N لمستوى …» line · then the feed, **grouped by date** («اليوم», «الخميس 2 أكتوبر», «أمس»):

- **session post** (`card` variant `post`): presenter row (avatar with team ring, name, company as
  team-colour text, venue · time) + phase `badge` · `poster` whole (the +50 sticker is drawn on the
  poster template, not by the card) · `reaction-bar` (❤ / 🔥 counts, comment count, share, bookmark)
  · **`session-cta`** as the last row — phase-aware: «احجز مقعدك» / «سجّل حضورك» (coral, live, with the
  «مقعدك محجوز» pill) / «قيّم الجلسة» / nothing when cancelled.
- **`race-bar` widget** («سباق الشركات»): top 2 + your company always, your row outlined accent;
  round label + days left.
- **achievement item**: level-up / badge / rank-change of a colleague, one line, react-only.
- **announcement item**: `surface-2` card with the megaphone glyph; admin author, no reactions.
- **recap post**: title with «اكتملت», presenter, attendance + photo count, 3-tile photo strip,
  «حمّل المواد» pill → materials.
- **propose band** («عندك موضوع؟») · `tab-bar`.

Desktop: same feed in the 600 px column (the post lays poster 260 px beside the copy); the HUD moves
into the **game rail** as four cards: rank (`#4 من 212`, the person above and the gap), streak + points
(the flame object), the race widget (4 bars), «التالية لك» (the member's own reservations).

States: **zero feed** (new org) → the date-grouped browse list inline, per 16 §6.6 · **no company
set** → `app.home.companyMissing` banner above the HUD, `session-cta` disabled with the reason ·
**staff** → «يحتاج انتباهك» strip under the HUD (counts as links). Moments: the **rank change** plays
on the HUD rank tile once per occurrence; the **points count-up + flame** plays on the HUD when the
member returns after an award (`DEC-195` static states apply). Feed ranking: committed-first, then by
start time within the day; reactions are `REQ-SCR-021` structural zeros.

## 6. SCR-011 browse · `Browse.dc.html`

## 7. SCR-012 event page · `Event.dc.html` · `EventLive.dc.html` · `EventDone.dc.html` · `EventDesktop.dc.html`

Immersive: no tab bar; **bottom action bar** = the one primary + bookmark + share. Order is `09`'s:

1. top row: back · breadcrumb («الجلسات › <category>») · bookmark · share
2. **`poster` whole**, 4:5 (the placeholder poster carries the team colour, title, date, presenter, QR)
3. chips row: phase `badge` · level · language (language precedes the action, `REQ-SES-011`)
4. `h1`
5. presenter `card` (avatar with team ring, name, title · company · «قدّمت N جلسات», → profile)
6. **action `card`**, in flow (`DEC-045`): seats `progress-bar` + «N من M» · **`session-cta`** ·
   icon rows: date-time · venue + «الخريطة» · deadlines (registration close · late-cancel cut-off,
   one line) · «شهادة حضور تلقائية» when the mode is automatic (`REQ-CRT-002`)
7. sub-nav chip row — **only sections with content**, scroll-spy on desktop
8. «ماذا ستتعلّم؟» (objectives, `text[]`, absent when empty) · `tag-chip` row
9. نبذة (`prose`) · المُقدِّمون (cards) · المهام التحضيرية (checkboxes, «N من M · تذكير فقط») ·
   **المواد with the phase gate**: before-phase rows are live, after-phase rows are a dashed locked row
   («يظهران هنا بعد انتهاء الجلسة») · النقاش (composer with @-mention hint + photo button; comments
   one level deep, replies indented; reactions on comments) · الصور (live/completed only)

**Live** (`EventLive`): coral badge with the dot · action card bordered coral: **live count** as a
display number + attendee avatar stack, `session-cta` «سجّل حضورك» coral with the «مقعدك محجوز» pill,
the rotation line («يُعرض في القاعة ويتغيّر كل 10 دقائق. +50 تصل عند انتهاء الجلسة») · «شاهد القصة»
entry in the top row (M20) · **الصور** opens: dashed «أضف صورة» tile for checked-in attendees, the
privacy line (EXIF stripped, «أزلني») · discussion continues. No register control.

**Completed, attended** (`EventDone`): «مكتملة» badge · **outcome card** bordered accent: «+50» coin
tile + «حضرت، ودُفعت نقاطك» + the timestamps (read-only fact, `REQ-SES-023`) · `session-cta`
«قيّم الجلسة» with the window end as a pill · certificate row (bone, code in `<bdi>`, download) ·
three recap `stat`s (attended of registered, photos, top reactions) · sub-nav · المواد **unlocked**
(slides PDF → viewer SCR-013, audio row with play + scrubber, listen-only) · الصور grid + «أضف صورة
من القاعة» · discussion. Bottom bar: «قيّم الجلسة» + «شهادتك». **Did not attend**: outcome card
says so in `fg-muted`, no rate CTA, no certificate, materials still unlocked. **Presenter viewing**:
outcome card becomes «قدّمت» +100 and «شاهد ملخصك». **Cancelled**: badge, the cancellation line,
comments frozen (`event.comments.frozenOnCancelled`), no actions, no sticker.

Other states not drawn: **full → waitlist** (CTA «انضم لقائمة الانتظار», then «أنت على قائمة الانتظار،
ترتيبك رقم N» with «غادر»), **reserved** (card shows «تم تأكيد حجزك» + «أضف للتقويم» + «إلغاء الحجز»
with the late-cancel warning after the cut-off), **deadline passed** (`rsvp.deadlinePassed`, no CTA).

Moments: **reservation** plays on `session-cta` once (`DEC-195`); **check-in** plays on SCR-014, not
here; **points count-up** plays on the outcome card on the first visit after the award.

Desktop (`EventDesktop`): hero band = poster 360×450 at start + chips, `h1`, abstract, presenter
card, tags at end · **full-width action row** (seats · CTA · bookmark · share · icon rows), sticky
once scrolled out of view (16 §6.3) · sub-nav under a rule · body grid **1fr / 380**: sections at
start; at end a venue card (map, capacity, «الحضور في القاعة فقط»), «من يحضر» avatar stack with the
company count, and a «لفريقك» race note. No game rail here — the page owns its width.

## 8. SCR-014 check-in · `CheckIn.dc.html`

Full-screen (immersive): close · `h1` «تسجيل الحضور» · session mini-row (thumb, title, «جارية الآن ·
venue · بدأت قبل N دقيقة», live pill) · centred prompt · **`code-input`**: six 48×60 boxes,
**`dir="ltr"`**, display face 30, filled boxes bordered accent, one label per box, `autocapitalize=off`
· the rules line («يتغيّر كل 10 دقائق، ويُقبل أثناء الجلسة فقط. لا حاجة لحجز مسبق») · earn `panel`
with the +50 sticker («تصل عند انتهاء الجلسة، مع الجلسة الثامنة في سلسلتك») · bottom bar with the one
`submit-button` + «لم تلتقط الرمز؟». States: **wrong code** — boxes shake once (allowed: it is not a
failure animation of the system, it is input feedback; reduced motion: border coral + message) ·
**rate-limited** (5 wrong / 10 min, `DEC-090`) — the boxes lock with the wait time · **already
checked in** — the screen is replaced by the checked-in state («سجّلت حضورك 6:41 م») · **success** —
the **check-in moment** (`DEC-195`) then return to the event page live state.

## 9. SCR-016 host view · `Host.dc.html`

Presenter/staff only, live: back · `h1` «شاشة التقديم» · «اعرض على الشاشة» (projection mode: the
code alone, display face ≥ 160 px, wake-lock) · session line · **the code in two groups of three,
`dir="ltr"`, display 84** · rotation line («يتغيّر بعد 6:12 · الرمز السابق يُقبل لدقيقتين») · live
count `stat` («23 من 40 حاضرًا · 3 حضور بلا حجز») · `switch` «تسجيل الحضور مفتوح» with the auto-close
time · «أبطل هذا الرمز الآن» (outlined coral — a real action, never accent) · «تسجيل يدوي» → the
manual `sheet` (member `combobox` + reason, `REQ-CHK-008`) · the footnote. Before `live`: the code
area shows «يُصدر الرمز عند بدء الجلسة» and the switch is disabled. After close: the count freezes
and the code area says «أُغلق التسجيل».

## 11. Deltas vs `docs/plan` — proposed decisions

- **`DEC-NEXT-16` — the shell has five phone tabs and a desktop nav rail + game rail.** Supersedes
  the four-tab, two-row header of `16 §6.1` / `REQ-UIX-021`. Search stays in the bar; staff links
  stay in the ruled section (both kept).
- **`DEC-NEXT-6` (already proposed) — home is the feed.** `/app` stops sharing a component with
  `/app/sessions` (`DEC-112` / `DEC-130` keep `/app/sessions` canonical for browse).
- **Hero poster on the event page is the whole poster at 4:5**, phone and desktop — no cropped
  16:9 band (`16 §4.2.2`'s dark band is retired by the playground's ground being dark already).
- **The «+50 عند الحضور» sticker is part of the poster template**, so the public card, the feed and
  the event page show it without a component drawing it (`REQ-UIX-024` unchanged: rendered posters
  are not restyled).
- `/app/members` (SCR-019) is confirmed a gap; it is in batch B.
- Open with the owner (unchanged): the overshoot ceiling `1.08` vs `03-motion.md`'s `1.22`.
