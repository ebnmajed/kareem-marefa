## 046 الأماكن · 047 التصنيفات · 048 الشركات · 049 الأعضاء
Four `data-table`s on the frame. **Venues**: name · **company** (the host; a venue belongs to one company, and a session held there
counts as that company's hosting, `05` company rules) · address · capacity · sessions; «مكان جديد».
The row's edit sheet has the company `select`; a venue with no company hosts for nobody.
**Categories** (`DEC-227`: no tags): name · sessions; «تصنيف جديد»; delete is blocked while sessions
use it (row menu says so). **Companies**: colour swatch · name · domain · members · active · the
quarter's company points; «شركة جديدة»; the row's edit sheet holds name, domains, colour, logo
(`REQ-ORG-*`). **Members**: avatar · name · company · role badge (مشرف / مُشرِف إشراف / موقوف) ·
level · points · last active; chips الشركة · الدور; «CSV»; the row menu changes role, suspends,
reactivates — each audited. No invite: members arrive by SSO.

## 050 · 052 البلاغات · 051 الصور
**Two screens, deliberately** (`09`, OQ-008): **takedown requests** are already hidden and await
review; **reports** are not hidden. `051` is a split view: queue (thumbnail · session · requester ·
age; chips طلبات الإخفاء / بلاغات الصور) and the detail (the photo large, session, uploader,
requester, status badge, «احذف نهائيًا» primary, «أعدها للعرض»). `050/052` is one table with chips
مفتوحة / التعليقات / مغلقة: content excerpt + author · session · reporter · reason · age · «أخفِ»
«تجاهل» inline. Every action audited (`REQ-ADM-010`).

## 053 النقاط
Read mode: the **fixed catalogue** (`REQ-PTS-010`) as a table — action · value · cap · cooldown ·
enabled `switch`; the negative group below at 0 «مغلق افتراضيًا»; the company rules as one line.
«عدّل» opens the same table editable with Save/Cancel; «تعديل يدوي» opens a sheet: member
`combobox` · points · reason (mandatory, audited, lands in the member's ledger as `row.manual`).
الحجز and التفاعل are absent, not zero.

## 054 الشارات والمستويات
Levels table (name · threshold · colour) beside the badges table (name · rule · granted · enabled);
«عدّل» for both. Below: **شهادات الإنجاز بانتظار الإصدار** (`REQ-CRT-012`, `DEC-050`): member ·
achievement · age · «أصدر» / «أوقف».

## 060 التذكيرات
One table: reminder · timing · channels · enabled; «عدّل». The set is `08`'s; a row is never added
here.

## 061 التصدير · 062 سجل التدقيق
Exports: one row per export (`admin.exports.*`), last run (actor · when), «CSV» — UTF-8 with BOM,
Arabic headers, Western numerals, sortable dates, **every export audited** (`REQ-ADM-017`). Audit:
chips الفاعل · الفعل · period; table time · actor · action · target; «CSV».

## 063 الإعدادات
Read mode, four `kv-card`s in two columns: المؤسسة (name, domains, language, time zone) ·
الجلسات (default capacity, registration close, late cancel, code rotation and window, waitlist,
proposal approval) · الخصوصية (photo stripping and retention, rating anonymity, member export
window, deactivation) · الربط (Google calendar, sender address, verify URL). One «عدّل».

## 064 الاستبانة · 065 الاستبانات
`064` is the hub's الاستبانة tab on a completed session: four `stat`s (responded / session avg /
presenter avg / response rate), a bar per star count, the free-text answers list with the
anonymity line (`REQ-RAT-*`), «CSV». `065`: templates table (name · questions · sessions ·
default) + the selected template's questions (question · type · required); «قالب جديد».

## Primitives
As built, plus the three from M11a. No new primitive in this batch. The `switch` inside a table
row needs a `data-table` cell variant; a story, not a primitive.
