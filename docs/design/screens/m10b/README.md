# m10b/ — the artboards behind docs/design/screens/M10b.md

Rows E and F of the design canvas «كريم معرفة · M10a + M10b — Member screens». Same conventions as
`m10a/`: each file is a self-contained HTML page (ignore the `support.js` line), 390 wide for phone and
1280 for desktop, a tall board is the whole page, a bottom bar drawn at the bottom is fixed in the product.

| file | screen |
|---|---|
| Viewer.dc.html · ViewerDesktop.dc.html | SCR-013 the viewer, phone (chrome revealed) · desktop |
| Rate.dc.html | SCR-015 rate, open |
| Propose.dc.html | SCR-017 propose, draft in progress |
| Proposal.dc.html | SCR-018 my proposal, changes requested |
| Directory.dc.html | SCR-019 directory (new page) |
| Profile.dc.html · ProfileDesktop.dc.html | SCR-020 profile, member tier, phone · desktop |

References for layout, sizes and copy; nothing in them is a component (`docs/design/README.md`).
`png/` takes one export per board from the canvas (Share › Export), named after its file.
