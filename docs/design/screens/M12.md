Row **K** of the canvas (4 artboards). Repo path `docs/design/screens/M12.md`. Against the pack of
2026-10-03 after wave 22 (`main` `242657a5`, next migration `0191`, next decision `DEC-235`). Rules

desktop-only (`06 §2`); the other three stack under `lg` like every console table.

Scope: **SCR-055 templates (two tabs) · 056/057 the designer (poster and certificate) · 058 emails ·

`059` branding and the platform console go with M13.

## 055 القوالب · `AdminTemplates.dc.html`
Tabs الملصقات · الشهادات. Two groups: **قوالب مؤسستك** and **قوالب المنصة** («انسخ لتعدّل» —
platform templates are read-only, `REQ-DSG-*`). A card = a 4:5 preview rendered from the template
with its bound fields as `{placeholders}` · name · «افتراضي» / «المنصة» · format chips · ⋯ (open,
duplicate, set default, archive). «قالب جديد» opens the designer on a blank of the chosen tab.

## 056 · 057 المصمّم · `AdminDesigner.dc.html` · `AdminDesignerElements.dc.html`

★ **Redesigned 2026-10-03 on the owner's ruling: a rich editor in the Mailchimp mould, on a free
canvas.** Not the current chrome restyled — the editor is rebuilt; `canvas.tsx`'s engine, the
bindings and the checks logic are kept under it.

**Layout — one sidebar.** A 68 px icon rail at the inline-start · a 300 px panel that **swaps** with
the rail's selection · the canvas · no right panel. Rail: العناصر (text styles, shapes, poster
frame, QR, company logo, the 3D objects and stickers as draggable assets) · الحقول (the session
fields as draggable bound text: title, presenter, date, venue, category) · الملفات (uploads,
brand-kit images) · الهوية (the brand kit's colours incl. the seven team colours by name, fonts,
logo) · الطبقات (list, reorder, lock, hide) · الفحوصات with a count · **الطبقة**, which appears when
a layer is selected and takes the panel (tabs النص / الموضع / التأثيرات for text; الصورة / الموضع
for images; QR: what it points at).

**Canvas.** Free positioning with handles, snap guides, rulers on demand, the safe area dashed,
grid and auto-align toggles on the canvas. **A floating toolbar above the selection** holds the
five things touched most (font, size, colour, alignment, «{ } ربط»); everything else is in the
panel. Double-click edits text inline. Drag from the panel drops a layer where it lands.

**Bar.** Back · name · «مسودة» / «محفوظ» · undo/redo · the **variant strip** (16:9 · A4 · A3 · 9:16 —
one template, every format; switching the chip switches the canvas; layers map across formats with
per-format overrides) · zoom · «معاينة بجلسة» (a real session's data) · «صدّر».

**Checks** are a rail item with a count, never a modal: contrast, minimum logo PPI for A3, the
longest title in the org fitted at the layer's max lines, safe-area violations; each names the
layer and selecting it opens the layer. A text layer's panel shows the longest title and whether
it fits.

### The certificate flows — two, drawn separately
**Template** (`AdminTemplatesCerts.dc.html`, `AdminCertDesigner.dc.html`): the library's الشهادات
tab lists the org's certificate templates and the platform's, each tagged with the kinds it serves
(حضور · تقديم · إنجاز), and names the **default for attendance/presenting** and the **default for
achievements**. Opening one is the same editor on a landscape canvas (A4 أفقي · A4 عمودي · A3 أفقي
on the variant strip) with the **الحقول** panel listing the certificate fields — {اسم العضو}
{نوع الشهادة} {عنوان الجلسة} {تاريخ الجلسة} {نص الشهادة} {الرقم التسلسلي} {تاريخ الإصدار} {التوقيع}
{رمز التحقق QR} and, for achievements, {المستوى} — each marked used / unused; «معاينة بعضو» renders
with a real member. A template is never per session.
**Session** (`045`): the session's الشهادات tab shows the mode (set once in الجدولة, `DEC-178`) and
**which template** it uses (the default unless the admin picks another in الجدولة before
completion); then held → release, issued → download / revoke. Achievement certificates are released
on `054` with the achievements default.

## 058 البريد · `AdminEmailGallery.dc.html` · `AdminEmails.dc.html` · `AdminEmailAdd.dc.html`

★ **Redesigned 2026-10-03: the Mailchimp new-builder model.** The message set is still `08`'s;
each message is a design the admin owns.

**Gallery.** A card per message: rendered thumbnail, name, category, مفعّلة / متوقفة, send count;
category chips; «رسالة جديدة» (from the fixed set); «سجل الإرسال».

**Editor — one sidebar.** Rail: إضافة · الأنماط · التخطيطات, and **الكتلة** when a block is selected.
*إضافة*: content blocks (نص · صورة · زر · فاصل · مسافة · **بطاقة الجلسة** · الملصق · رمز QR · نقاطك ·
شهادة · الشعار · اجتماعي) and layouts (1 · 1/1 · 1/2 · 1/1/1); drag into the email, a dashed «أفلت
هنا» slot shows between rows. *الأنماط*: the email's defaults — font, heading sizes, text and link
colours, button style, padding, background — desktop/mobile linked by default, unlinkable per block.
*الكتلة*: tabs المحتوى / النمط, the variables as chips ({اسم العضو} {عنوان الجلسة} {الموعد} {المكان}
{المُقدِّم} {رابط الجلسة} {آخر إلغاء}), «استعد الأنماط الافتراضية».

**Canvas.** The email at 600 px on a neutral ground; every row selectable with a hover handle bar
(label · drag · duplicate · delete); inline text editing with a floating toolbar; the device toggle
renders the mobile width. **بطاقة الجلسة** is a bound block (poster, title, time, venue, presenter).
Bar: back · name · «مسودة» · undo/redo · device toggle · «معاينة واختبار» (real session + test send)
· «احفظ وفعّل». Output is responsive; the brand kit's fonts and colours are the defaults.

## 045 إعدادات الجلسة — الشهادات · `AdminCertificates.dc.html`
The hub's الشهادات tab on a completed session. The mode as a sentence (`DEC-178`: «الوضع: تُراجع
قبل الإطلاق» / «تلقائية» / «لا تُصدر»; set once, from الجدولة) and the template. **محجوزة**: a table
with row checkboxes, «أصدر المحدّد» (primary) / «أصدر الكل»; **صادرة**: member · kind · serial
(`<bdi dir="ltr">`) · issued · «PDF» (audited download) · «ألغِ» (reason mandatory, in a sheet).
Achievement certificates are not here (`054`).

## Primitives
New: `editor-rail` (icon rail + swapping panel, shared by both editors) · `canvas-stage` (free
canvas, handles, snap, safe area, rulers) · `floating-toolbar` · `layer-list` · `block-canvas`
(rows, drop slots, hover handle bar) · `block-library` (the grid). The engine files in
`components/designer/` stay logic. No motion in the studio beyond drag feedback.

## Deltas

  separate template.
- `DEC-NEXT-34` — checks are a tab with a count, never a modal; the PPI guard explains inline.
- `DEC-NEXT-35` — emails are block-based in the Mailchimp model (blocks + layouts + global styles
  + per-block overrides); the message set is `08`'s.
- `DEC-NEXT-36` — both editors share one sidebar model: an icon rail and a panel that swaps; no
  right panel; a floating toolbar on the selection.
